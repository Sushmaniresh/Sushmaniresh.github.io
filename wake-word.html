A wake word in 377 parameters.

Real-time, fully offline keyword spotting: one-second microphone windows become log-mel spectrograms, and a CNN small enough to live on a microcontroller says yes or no every 200 ms.

Problem

Wake-word detection runs all day on a battery. It has to be always on, never phone home, and fit in kilobytes. The exercise was to find out how small a model can be before it stops hearing you, and to build the live loop around it, not just the training script.

Approach

record → mel → tiny CNN → stream

I recorded my own wake and not-wake clips, computed 40-bin log-mel spectrograms at 16 kHz, and trained the smallest network that would still separate them. Two convolutions, batch-norm, a global average pool, and a four-unit bottleneck. An LSTM variant with a hidden size of 4 sits alongside it for comparison.

# tiny-pytorch/src/model.py
class TinyWakeWordCNN(nn.Module):
    def __init__(self):
        super(TinyWakeWordCNN, self).__init__()
        self.conv1 = nn.Conv2d(1, 4, kernel_size=3, padding=1)
        self.bn1 = nn.BatchNorm2d(4)
        self.pool1 = nn.MaxPool2d(2)

        self.conv2 = nn.Conv2d(4, 8, kernel_size=3, padding=1)
        self.bn2 = nn.BatchNorm2d(8)
        self.pool2 = nn.MaxPool2d(2)

        self.global_pool = nn.AdaptiveAvgPool2d(1)
        self.fc1 = nn.Linear(8, 4)
        self.fc2 = nn.Linear(4, 1)

    def forward(self, x):
        x = F.relu(self.bn1(self.conv1(x)))
        x = self.pool1(x)
        x = F.dropout(x, 0.2)
        x = F.relu(self.bn2(self.conv2(x)))
        x = self.pool2(x)
        x = F.dropout(x, 0.2)
        x = self.global_pool(x)
        x = x.view(x.size(0), -1)
        x = F.relu(self.fc1(x))
        x = torch.sigmoid(self.fc2(x))
        return x

The inference loop is the part people skip. A deque holds one second of audio; a sounddevice callback appends 200 ms blocks; every block the buffer becomes a spectrogram, runs through the model, and prints a probability bar in the terminal.

# tiny-pytorch/src/inference.py: the live loop
FRAME_SIZE  = int(1.0 * 16000)
STRIDE_SIZE = int(0.2 * 16000)
audio_buffer = deque(maxlen=FRAME_SIZE)
stream = sd.InputStream(
    callback=lambda indata, frames, time, status: audio_buffer.extend(indata[:,0]),
    channels=1, samplerate=16000, blocksize=STRIDE_SIZE)

with stream:
    while True:

The honest part

100% validation accuracy on a small, partly synthetic dataset means the models fit this data. It does not mean they survive a kitchen with a dishwasher running. The README says so, and the next steps are written down: test on noisy real-world audio, report false accepts per hour, then quantize and deploy to a microcontroller.
