Can a forearm be a password?

Surface EMG from 43 people doing 16 hand gestures. Time-domain features and a Random Forest identify who is who at 76% — and the write-up is explicit about why identification is not yet authentication.

Subjects
43GRABMyo · 3 sessions each · ≈9 GB
Channels

Identification accuracy
76%macro-F1 0.75 · 1,024 test recordings

Problem

Muscle activation patterns are shaped by anatomy, so in principle they are personal. The open question is whether that signal is stable enough, across days and gestures, to use as a biometric. Step one is identification: given a recording, which of 43 people made it?

Approach

features → forest · filter → spectra · a CNN waiting for data

Five time-domain statistics per channel — mean, standard deviation, RMS, skewness, kurtosis — stacked into a feature vector, then a 100-tree Random Forest on an 80/20 split. A PCA of the feature space already shows subject clusters separating.

# notebooks/01_feature_extraction_random_forest.ipynb
from scipy.stats import skew, kurtosis

def extract_features(signal):
    feats = {}
    for i in range(signal.shape[1]):
        channel = signal[:, i]
        feats[f"mean_ch{i}"]     = np.mean(channel)
        feats[f"std_ch{i}"]      = np.std(channel)
        feats[f"rms_ch{i}"]      = np.sqrt(np.mean(channel**2))
        feats[f"skew_ch{i}"]     = skew(channel)
        feats[f"kurtosis_ch{i}"] = kurtosis(channel)
    return feats

A second notebook does the signal work: band-pass and notch filtering, 250 ms windows with 50% overlap, Welch power spectra per channel. And an experimental 2D-CNN treats the (channels × time) window as an image — written, windowed and z-scored per channel with training-session statistics, but not yet adapted to the full 32-channel data, so it reports no numbers.

# experimental/emg_id_cnn.py
def zscore_per_channel(x, mean, std, eps=1e-8):
    return (x - mean) / (std + eps)

class EMG2DCNN(nn.Module):
    def __init__(self, n_classes: int, in_ch=1):
        super().__init__()
        # Treat (C=8, T) as an "image": add a fake 1 channel dim -> (N, 1, 8, T)
        self.features = nn.Sequential(
            nn.Conv2d(in_ch, 16, kernel_size=(3,5), padding=(1,2)),
            nn.BatchNorm2d(16), nn.ReLU(inplace=True), nn.MaxPool2d((2,2)),
            nn.Conv2d(16, 32, kernel_size=(3,5), padding=(1,2)),
            nn.BatchNorm2d(32), nn.ReLU(inplace=True), nn.MaxPool2d((2,2)),
            nn.Conv2d(32, 64, kernel_size=(2,3), padding=(0,1)),
            nn.BatchNorm2d(64), nn.ReLU(inplace=True),
            nn.AdaptiveMaxPool2d((1, 8)),        # -> (64, 1, 8)
        )
        self.classifier = nn.Sequential(
            nn.Flatten(), nn.Dropout(p=0.3),
            nn.Linear(512, 256), nn.ReLU(inplace=True),
            nn.Dropout(p=0.3), nn.Linear(256, n_classes))

Why 76% is not a login screen

Two caveats, both stated up front in the README. This is identification (which of 43?) rather than verification (is this the claimed user?), so EER, FAR and FRR are not computed yet. And train and test come from the same session, while EMG drifts across days — cross-day testing is the honest benchmark.

  1. Select fewer electrodes using muscle anatomy and per-electrode ANOVA power.
  2. Turn the spectral features into a 2D-CNN input and finish the experimental model.
  3. Evaluate as authentication: EER, FAR, FRR against prior work.
  4. Train on two days, test on the third.
