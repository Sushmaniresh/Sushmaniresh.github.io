Arrhythmia, beat by beat.

An end-to-end pipeline on the MIT-BIH database: from raw two-lead recordings, through filtering and heart-rate variability, to classical models and a 1D-CNN / BiLSTM, selected on macro-F1, not accuracy, and checked with saliency maps.

Dataset
48half-hour recordings, 2 leads, cardiologist beat labels
Classical models
5LogReg · KNN · RBF-SVM · RF · XGBoost, nested CV
Deep models
21D-CNN · 2-layer BiLSTM on beat windows
Selected on
macro-F1plus AUC-PR, sensitivity, specificity

Problem

Arrhythmia labels in MIT-BIH are brutally imbalanced: normal beats dominate, the clinically interesting classes are rare. A model can score 95% accuracy by never predicting the thing you care about. The question was less "which model wins" and more "which pre-processing and which metric tell the truth".

Approach

three stages, one notebook, three PDF write-ups

01 Signal. Records streamed with wfdb, nothing stored locally. Fourth-order Butterworth band-pass for baseline drift and muscle noise, a notch at power-line frequency, then FFT and spectrogram views across ten random records to pick cut-offs by eye before trusting them by number. R-peaks → RR intervals → time- and frequency-domain HRV.

# ECG_analysis.ipynb: filtering and R-peak detection
def bandpass_filter(sig, fs, lowcut=0.5, highcut=40.0, order=4):
    nyq = 0.5 * fs
    b, a = butter(order, [lowcut/nyq, highcut/nyq], btype='band')
    return filtfilt(b, a, sig)

def detect_r_peaks(ecg, fs):
    distance = int(0.25 * fs)  # min 250ms between peaks
    threshold = np.mean(ecg) + 0.5*np.std(ecg)
    peaks, _ = find_peaks(ecg, distance=distance, height=threshold)
    return peaks

def hrv_time_domain(rr_intervals):
    mean_rr = np.mean(rr_intervals)
    sdnn = np.std(rr_intervals)
    rmssd = np.sqrt(np.mean(np.diff(rr_intervals)**2))
    return mean_rr, sdnn, rmssd

02 Classical ML. Segment beats, extract features, and compare Logistic Regression, KNN, RBF-SVM, Random Forest and XGBoost under nested cross-validation with hyper-parameter tuning. Scored on sensitivity, specificity, precision, recall, F1, AUC-ROC and AUC-PR. XGBoost came out on top.

03 Deep learning. Lead II only, 5-40 Hz band-pass, per-record z-score, polarity correction, R-peaks from PhysioNet's XQRS, one window per beat. A 1D-CNN and a two-layer bidirectional LSTM, model selection on macro-F1 so the rare classes get a vote. Saliency maps over single beats confirm the network attends to the QRS complex.

What I'd tell the next person

Filtering choices move results more than model choices. The band-pass range, the notch, and polarity correction each changed downstream F1 noticeably; swapping classifiers often did not.

On imbalanced medical data, macro-F1 and AUC-PR are the metrics to argue over. Accuracy should not appear in the headline.

Interpretability is a test, not a figure. A saliency map that lights up the QRS complex is evidence the model learned physiology; one that lights up the baseline is a bug report.
